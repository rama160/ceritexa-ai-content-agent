How Google and YouTube access is used

With the channel owner's permission, the agent uses the official YouTube Data API to verify the selected channel, upload approved video drafts as private videos during the pilot, and obtain available performance statistics for that owner's content. Two separate channel authorizations are used for Panex and Heros Real Life.

The tool does not sell YouTube account information, share OAuth credentials with unrelated projects, or publish unauthorized videos. Access can be revoked through Google Account permissions at any time. Our Privacy Policy explains data storage, purposes, and deletion requests.

Owner dashboard

The private dashboard is intended for the authorized creator to review drafts, manage media, approve content and check integration status. Access requires an administrator credential. The dashboard is a separate interface from this public informational website.
