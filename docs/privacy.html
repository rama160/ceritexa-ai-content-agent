Privacy Policy

This policy explains how the Ceritexa Studio AI Agent accesses, uses, stores, and removes information when authorized channel owners connect Facebook Pages or YouTube channels.

Effective October 26, 2026

1. Operator and purpose

Ceritexa Studio AI Agent (“Ceritexa”, “we”, “our”) is an independently operated, creator-controlled tool for the Ceritexa Studio Facebook Page and the Panex and Heros Real Life YouTube channels. The service researches creative ideas, generates original fictional drafts and media concepts, requires owner review, assists scheduling, and analyzes performance data from connected channels.

2. Information we process

  • Google / YouTube API data: identifiers, channel names, identities needed to confirm the chosen channel; available video identifiers, titles, descriptions and performance statistics such as views, likes and comments, as requested by the authorized owner.
  • Google OAuth credentials: authorization/refresh tokens granted by the channel owner to access the YouTube API on the owner's behalf. We do not collect Google account passwords.
  • Facebook Page data: Page identifier, Page name, Page authorization token and available post-performance metrics when the operator authorizes access.
  • Creator-submitted content: story drafts, titles, captions, uploaded images or videos, internal approval decisions, scheduled publishing details and processing logs.
  • Technical information: limited operational records necessary to diagnose failures, prevent duplicate publishing and secure administrative access.

3. Why and how data is used

We use authorized YouTube data only to confirm which creator-owned channel is connected, upload videos that the channel owner approves (private during the pilot), display content status, retrieve available performance metrics, and suggest future editorial topics for that creator. Facebook Page data is used for the same operational purpose for the authorized Ceritexa Studio Page.

AI is used to generate original fictional text and visual drafts based on general story topics. Creator-specific engagement metrics may inform editorial topic selection; we do not train general-purpose AI models on Google user data or sell that data for advertising.

4. Permissions requested

  • https://www.googleapis.com/auth/youtube.upload — upload approved videos on behalf of an authorized channel owner.
  • https://www.googleapis.com/auth/youtube.readonly — verify channel identity and read permitted channel and video information.

The owner can decline or revoke these permissions. The tool does not request access to Gmail, Google Drive, banking information, or unrelated accounts.

5. Storage, retention and security

We use an isolated Cloudflare Worker, Cloudflare D1 database and a private Cloudflare KV media store for the Ceritexa project. OAuth tokens are configured as Cloudflare Worker secrets, not stored in public GitHub source files or public website pages. Private management endpoints require an administrator credential. Limited automated video rendering may run in a private GitHub Actions job.

Drafts, scheduled jobs and stored analytics are retained while needed for the creator's content management and performance tracking. Revoking API permissions stops future authorized access but does not itself automatically erase previously stored drafts or statistics. The creator may request removal of stored records, media and connected credentials using the contact details below, and an administrator will handle the deletion through the relevant project storage and secret controls.

6. Data sharing and service providers

We use Google APIs for authorized YouTube actions, Meta APIs for authorized Facebook Page actions, Cloudflare for secure application hosting and storage, and GitHub Actions for approved internal video-rendering workflows. Information is shared only as needed to provide those functions or as required by law. We do not sell personal data or transmit creator OAuth tokens to other business projects.

7. Google API Services User Data Policy

Ceritexa's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including applicable Limited Use requirements. The tool does not use Google API user data for unrelated advertisements or generalized model training.

8. Revoking permissions and deleting data

To disconnect Google, visit Google Account → Third-party connections and revoke Ceritexa's access. To disconnect Facebook, use Facebook settings for business integrations and revoke Ceritexa's Page access. For stored data deletion, access correction, privacy questions or complaints, contact asriramavirgo98@gmail.com with the subject “Ceritexa Privacy Request”. Do not include access tokens, passwords or other secrets in that message.

9. Children's information

The service is operated for authorized channel owners and is not designed to collect personal information from children. Fictional content may be suitable for a general audience, but the administration system is not a children's account service.

10. Updates

We may update this policy when the application's functionality or provider rules change. The effective date will be updated on this page.
